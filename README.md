# Predictive Modeling Using Machine Learning

## Overview
This project demonstrates supervised machine learning using a Random Forest Classifier.

## Features
- Data preprocessing
- Model training
- Model testing
- Accuracy evaluation
- Confusion Matrix visualization
- ROC Curve visualization

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn

## Machine Learning Algorithm
Random Forest Classifier

## Outcome
The project predicts outcomes using machine learning and evaluates performance through multiple metrics.
